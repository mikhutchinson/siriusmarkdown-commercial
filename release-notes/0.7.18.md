# SiriusMarkdown 0.7.18

Highlight marks compose with bold, italic, strikethrough, links and inline code.
For example, `==**~~word~~**==` renders one highlighted, bold, struck word without
showing its delimiters. Each semantic child retains its authored content range
and link destination. Code, math, HTML attributes and link destinations cannot
supply highlight delimiters.

macOS prepared native text now paints strikethrough, including when combined
with bold. Highlight backgrounds and source-backed selection remain available.

macOS drag selection applies the final mouse-release position, including when
AppKit coalesces intermediate mouse moves. Selecting through a sentence ending
no longer stops at the last delivered move.

Swift Package products, public API signatures and minimum platforms are unchanged.
The independently versioned browser distribution is unchanged.
