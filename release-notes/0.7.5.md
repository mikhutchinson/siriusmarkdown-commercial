# SiriusMarkdown 0.7.5

October 12, 2026

Native equations and diagrams advance while Markdown is still streaming. Useful
prepared prefixes can publish during continuous input, and supported native
children appear inside unfinished Mermaid containers and math boxes, fractions
and matrices. The semantic parsers own these drafts; authored source is preserved
without adding closing syntax. Finished and unsupported input keeps strict
admission and deterministic source fallback.

Diagram surfaces preserve camera state as their resources grow. Native PDF
selection follows unambiguous semantic labels across page replacements, including
active selection controls on supported UIKit versions. Replacing the document
clears its camera and selection. Closed empty flowchart subgraphs and state
composites render their native boxes and titles.

Math now supports native `\not` overlays, named single and double vertical
delimiters, extensible `\xrightarrow` and `\xleftarrow` relations with labels,
point-valued equation row gaps and multiple column pairs in `aligned`. These
expressions share native raster, accessibility and vector-export preparation.
Text labels retain TeX escaping rules: use `\text{masses \& mixing}` for a literal
ampersand. An unescaped `&` inside `\text` is rejected as invalid source.

HTML subscript and superscript glyphs retain their full height in compact prose
and table cells, including expressions such as H₂O. Math pixels are decoded during
preparation and cached within bounded resource limits. Cancelled image loads
remain counted until they exit, so image-idle waiting drains retiring requests
and document or viewport replacements cannot publish their late results.

Theme presets retain their typography and independent value semantics when
constructed on worker threads. Released prepared-artifact initializer signatures,
renderer hooks and prepared-snapshot integrations remain supported.
Use `MarkdownRenderSession.presentation` and its bound source-access configuration
when rendering and copying must refer to the same displayed prefix. Custom
renderers can adopt `MarkdownStreamingMathRenderer` or
`MarkdownProgressiveMermaidRenderer` for typed progressive outcomes. See the
[streaming guide](../Docs/streaming.md) and [native math guide](../Docs/math.md)
for integration details and supported syntax.

Update the `siriusmarkdown-commercial` dependency to 0.7.5 and rebuild your app.
The binary package continues to require Swift 6.3 and supports macOS 13,
iOS/iPadOS 16 and visionOS 1; individual interactions have platform-specific
availability.
