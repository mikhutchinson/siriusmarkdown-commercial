# SiriusMarkdown 0.7.1

This patch corrects document Find and fragment navigation, including long
documents with large tables, code, images, math, diagrams and sanitized HTML.

- Find reveals the actual rendered occurrence and its source highlight, including
  horizontally hidden table cells and code. The destination remains aligned while
  lazy content settles, prepared content changes or the viewport is resized.
- Next and Previous reveal a single result again after the reader scrolls away.
  New commands, reader interaction, Find dismissal, document replacement and
  view removal supersede obsolete navigation.
- Heading fragments and sanitized HTML IDs use the same native reveal behavior.
  Empty IDs reveal their real block or neighboring content without adding text.
- Text beside semicolon-terminated HTML character references keeps its exact
  source range; each decoded reference maps to its complete authored span.
- Long code remains contained inside the horizontal scroller of a host-scrolled
  reader. UIKit source highlights use the same prepared font metrics as the text.
- Find works with native leaf selection and with document selection ordinarily
  disabled. Resizing an AppKit window preserves the active source selection.

The public APIs and supported binary platforms are unchanged: Swift 6.3 or
later, macOS 13, iOS/iPadOS 16 and visionOS 1. Update the resolved package to
0.7.1 and rebuild your application to receive these corrections.

See [document interactions](../Docs/document-interactions.md) for integration
and matching limits.
