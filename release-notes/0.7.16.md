# SiriusMarkdown 0.7.16

Rendered editing retains current input geometry when SwiftUI delivers a late
geometry callback from an earlier document snapshot. Replacing list, task or
quoted content no longer leaves the next native editing command waiting for
geometry that was already prepared.

Geometry still belongs to its matching source generation. Stale callbacks cannot
relabel old layout or overwrite the current mount. Native input ordering, source
selection and the public authoring APIs remain unchanged.

This release includes the writing and list preparation improvements in 0.7.15.
Swift Package products and minimum platforms are unchanged. The independently
versioned browser package is unchanged.
