# SiriusMarkdown 0.7.6

October 17, 2026

Fix macOS paragraphs and inline equations wrapping into a narrow column and
overlapping following blocks during streaming or updates to a mounted view.
Speculative width measurements now use separate native text-layout state;
the accepted placement sets the displayed text geometry. A rejected sizing
proposal can no longer leave the live text view at the wrong width until
another layout or reload.

Mounted text identity, selection, source mappings, prepared math attachments,
and cached content are preserved. Offscreen rendering and export initialize
the same accepted text geometry. Public APIs and platform requirements are
unchanged.

Update the `siriusmarkdown-commercial` dependency to 0.7.6 and rebuild your app.
The binary SDK requires Swift 6.3 and supports macOS 13, iOS/iPadOS 16, and
visionOS 1; individual interactions have platform-specific availability.
