# SiriusMarkdown 0.7.19

Unchecked task items remain unchecked when their text contains literal `[x]` or
`[X]`, including in code, links, quoted tasks and nested lists. Task recognition,
nesting and source ranges continue to come from swift-markdown; only the authored
opening marker supplies the completion state.

Checked and empty tasks retain their state. Streaming body text cannot toggle
an existing task. Public API signatures, products and minimum platforms are
unchanged. The independently versioned browser distribution is unchanged.
