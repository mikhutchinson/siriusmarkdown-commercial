# SiriusMarkdown 0.7.24

Mermaid flowcharts now render labels such as `A[Draft; review]` without adding
quotes or editing the Markdown. A semicolon inside a delimited node or edge
label stays in the displayed text, while a semicolon between statements still
separates them. The same syntax works in streamed drafts and in PDF, SVG and
text exports. An unfinished label stays pending during streaming, and completed
unsupported input still displays its source.

The package keeps its existing public APIs, products and minimum platforms.
The separately versioned browser distribution includes the same parser fix
in Browser 0.2.16.
