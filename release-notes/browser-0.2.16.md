# SiriusMarkdown Browser 0.2.16

Mermaid flowcharts preserve semicolons inside delimited labels such as
`A[Draft; review]`. Semicolons between statements remain separators. The fix
applies to streamed drafts, displayed diagrams and exports, and does not
require changing the authored Markdown.

Both WebAssembly reactors include the shared engine from native SDK 0.7.24.
Update the complete runtime together, including workers, JavaScript, fonts
and both WASM modules. The manifest records the native version and engine
source hash.
