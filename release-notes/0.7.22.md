# SiriusMarkdown 0.7.22

Text source ranges retain complete authored entity and escape spellings. URL
decoration no longer shortens ordinary text ranges using decoded byte counts.
Highlight processing preserves text and surrounding styles when a host splits
an existing highlight around a selected span. Escapes and references decode
once; encoded equals signs and dollar signs do not introduce authored syntax.
Source columns also reconcile the semantic parser's replacement of a NUL byte
with U+FFFD, preserving later text and delimiter positions.

For example, `==alpha &amp;amp;== **beta** ==gamma==` renders the visible text
`alpha &amp; beta gamma`, with bold beta outside the highlighted portions.
Formatting requests still leave source transactions, revision checks, selection
restoration and Undo with the host.

`MarkdownInlineRun.styleSources` now includes exact parser-owned inline-code
fences and any adjacent padding omitted from the visible code. Prefix and suffix
spellings can differ. The code run's `sourceRange` still covers its complete
token. Literal code contents remain opaque, and missing or unreconciled source
does not grant edit authority. Code recognition continues to follow
`swift-markdown`; the source-mapping layer does not classify unrecognized
backticks as code.

Exact `sourceTextMappings` and bidirectional UTF-8 range helpers now preserve
partial selections across entities, escapes, normalized line endings and code
boundaries. Native text-input geometry and source-based clipboard text use those mappings;
selecting `gamma` inside a code span no longer drops its first letter.
Read-only code dragging retains its whole-token selection behavior.
Text-input geometry retains only mappings intersecting each rendered line;
paragraphs with many entities avoid duplicating their full map for every line.

Existing public initializers, package products and minimum platforms remain available.
The independently versioned browser 0.2.14 distribution carries the same shared
engine and source metadata through its worker, copy and readable-print APIs.
