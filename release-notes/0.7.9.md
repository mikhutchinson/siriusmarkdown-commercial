# SiriusMarkdown 0.7.9

October 20, 2026

This release expands native Mermaid diagrams while preserving selectable vector
PDF, sharp SVG exports, exact authored source and strict completed-input fallback.
The native and browser engines share parsing, preparation and layout.

- Gantt supports UTC date/time programs, decimal and calendar durations, forward
  dependencies, working calendars, configured axes, markers and compact rows.
  Complete task names remain available in dense schedules and exports.
- GitGraph preserves delayed forks, parallel histories, branch identity and
  configured visibility and layout. Compact flow links and sequence activity
  lifetimes retain their authored topology and chronology.
- XY charts retain named and repeated series, unequal series lengths, precise
  numeric categories, point labels, authored line/symbol styles and full legends.
  Prepared mark rendering prevents replacement crashes as category sets, series
  and orientation change. Captions and leaders clear plotted ink.
- Pie charts support true donuts, all five legend positions, measured wrapped
  keys, authored colors and text/stroke controls. Zero and duplicate rows remain
  complete; precise and very large quantities keep truthful proportions and text.
  Quoted strings, escapes, multiline labels, comments and accessibility metadata
  share one strict grammar. Entity quotes remain label data in SVG exports.
- Quadrant diagrams gain authored point styles, measured references and layout
  controls. Journey and Timeline labels use contrasting ink on prepared fills.
- Diagram Find uses complete painted logical labels and source-backed ranges.
  Streaming preserves parser-owned statements, exact frontiers and source exports.
  Native bitmap exports remain upright and honor transparent themes.

See the [diagram guide](../Docs/Native-Mermaid.md) for supported syntax,
configuration and limits. Unsupported completed statements retain the source
fence; this release does not claim complete Mermaid.js syntax coverage.

Update `siriusmarkdown-commercial` to 0.7.9 and rebuild your app. The Swift Package
products and platform requirements are unchanged. Browser 0.2.5 is a separately
versioned distribution.
