# SiriusMarkdown 0.7.20

Read-only macOS streams now mount native Markdown content around the host's
viewport. Historical offscreen text, tables and figures no longer all participate
in native layout as incoming text grows the host. Source, prepared models and
stable scroll destinations remain available for the complete document.

Inert HTML anchors retain their empty native geometry, so revealing an offscreen
anchor does not replace an estimated spacer and change document height.

Find and fragment navigation materialize their source destinations. SDK diagram,
code and selection state follow source identity. Host-boundary content stays
mounted, and rendered editing retains its complete input geometry. Custom styles
that need every offscreen view mounted can use
`StreamingMarkdownView.offscreenContent(.retained)`. Automatic behavior on other
platforms is unchanged.

Unchecked tasks retain their unchecked state when their body contains literal
`[x]` or `[X]`. Task recognition and source ranges remain owned by swift-markdown.

Package products and minimum platforms are unchanged. The independently
versioned browser distribution is unchanged.
