# SiriusMarkdown 0.7.15

Rendered Backspace and forward Delete use the caret's actual wrapped line,
including composed Unicode characters and direction at line boundaries.
Clicking a new insertion point resets the preferred column for vertical movement.

The insertion point paints through a bounded native surface, independently from
document layout. Empty-paragraph layout updates remain separate from caret movement.
A replacement snapshot publishes input geometry only after its matching layout pass.

Hosts can route native events through
`MarkdownTextInputController.performEditingOperation(requiresCurrentGeometry:_:)`
to preserve input order while current rendered geometry is being prepared. Ordinary
insertion can proceed immediately; commands that depend on geometry wait, with
subsequent input kept behind them. Hosts retain text storage, input methods,
revision validation, persistence and native Undo. Finish accepted events before
save, export or mode changes; cancel them when abandoning a document.

Growing native lists reuse completed groups of prepared items and their measured
heights. Width, style and content changes still update the mounted native views;
source selection and Markdown semantics remain intact.

Swift Package products and minimum platforms remain unchanged: macOS 13,
iOS/iPadOS 16 and visionOS 1. This release does not update the browser package.
