# SiriusMarkdown 0.7.14

Fix paragraphs containing inline equations and source line breaks repeating raw Markdown
in the native reader. Exact AST break ranges are resolved before math-span coalescing,
with prepared geometry and source-backed selection preserved.

Mac and iPad now share native CoreText text-flow PDF pagination. Wide and long tables
retain their selectable cells across page breaks; vector diagrams and explicit raster
export modes keep their existing contracts.

Native input and task activation are available through ordinary public SDK interfaces.
Hosts retain their native text storage, input methods, revision checks and Undo manager;
the input bridge maps prepared glyph geometry to UTF-8 source-byte selections.
Stale geometry cannot authorize deletion of a nonempty source selection.

Read-only diagram source analysis delegates to the same strict native Mermaid parser
used for rendering. SDK-owned Sendable projections expose source-editing metadata
without exporting vendor parser models. Analysis preserves one captured Gantt reference
instant, honors cancellation and rejects invalid completed input and oversized source.

Outline controls can reveal current block IDs through the document’s existing native
navigation pipeline, including before mounting, without opening Find or building its index.

Swift Package products and minimum platforms remain unchanged: macOS 13,
iOS/iPadOS 16 and visionOS 1. The separate browser package remains at 0.2.11.
