# SiriusMarkdown browser 0.2.1

October 18, 2026

Prepare interactive diagrams in a dedicated worker with batched document-font
measurements. Streaming completes a coherent prefix while coalescing queued
appends; replacement source, theme changes and reset revoke obsolete work.
Unchanged accepted statements reuse preparation while authored source and
frontier metadata stay current. Diagram preparation and mounting have separate
diagnostic timings from publication application.

Flowcharts preserve authored reading order through feedback loops, including
nested groups that share a direction. Connections keep their authored
endpoints, labels and arrowheads. Class-diagram composition and aggregation
diamonds remain visible outside their endpoint nodes. Equations retain vector
output through preparation and source-only updates.

Selection placement observes browser geometry only while a range is selected
and releases that work on document reset or host destruction.

[Download browser 0.2.1](https://github.com/mikhutchinson/siriusmarkdown-commercial/releases/tag/browser-0.2.1)
or try the [playground](https://siriusmarkdown.com/playground/). Keep the worker,
consumer JavaScript, fonts and WASM modules together when upgrading. Follow the
[web page API](../Docs/web-page-api.md) for integration and resource policies.

The public playground uses static hosting and direct browser requests;
cross-origin resources require readable CORS responses. The optional resource
gateway remains a self-hosted integration. Browser printing and clipboard
formats differ from native APIs. This release does not claim complete native
capability parity or exhaustive mobile-device coverage. The native Swift SDK is
0.7.7 with its existing XCFramework products.
