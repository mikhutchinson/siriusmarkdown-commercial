# SiriusMarkdown 0.7.10

Class diagrams now draw nested and reopened namespace groups, display labels
and compact namespace projection. Cross-namespace relationships enter classes
at a normal angle; arrowheads remain visible and captions reserve clear space
along their routes. Native PDF/SVG, accessibility descriptions and native text
exports retain namespace ownership and complete labels.

Static member underlines and abstract member italics retain the full member
signature. Unicode names use prepared native font measurements, and native text
exports account for wide Unicode cells.

Default and bundled palettes provide stronger label, connector and node-outline
contrast in light and dark appearances. Explicit custom colors and translucent
artwork remain authoritative. Native relationship captions and semantic shape
outlines use the same paint roles as SVG.

Existing Swift Package products and minimum platforms are unchanged. The browser
package is released separately as 0.2.8.

PDF text extraction can normalize composed Unicode, and some color emoji lose
joiners or modifiers in copied text. Source and SVG retain the authored Unicode;
use Copy Source when exact source text is required.
