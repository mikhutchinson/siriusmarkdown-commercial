# SiriusMarkdown 0.7.17

Streams with an attached `MarkdownDocumentFindController` reuse completed render
regions while Find is closed. Navigation retains its forwarding link action and
render revision across appends, avoiding reconstruction of unchanged native text
and completed list groups. The mutable tail still follows normal Markdown
semantics; a growing list remains one semantic list.

Fragment navigation, Find, source selection and copy remain available. Replacing
a public renderer configuration still invalidates rendered content, and retained
link routes use the current host callback, including a replacement assigned
through `configuration.linkAction?.open`.

Swift Package products, public API signatures and minimum platforms are unchanged.
The independently versioned browser package is unchanged.
