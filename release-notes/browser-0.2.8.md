# SiriusMarkdown Browser 0.2.8

Class diagrams draw nested and reopened namespace groups, display labels and
compact namespace projection using the same Swift parser and layout as native
SiriusMarkdown. Relationship arrows enter node boundaries normally and retain
clear captions and visible arrowheads.

The shared document palette improves default outline and label contrast.
Browser mounting, expansion and SVG export preserve the engine's caption,
header and outline colors, including authored overrides. Light and dark
appearances retain the same semantic paint roles as native diagrams.

The download contains compiled WebAssembly reactors, JavaScript integration
modules, fonts, licenses and the required modified ElkSwift corresponding
source. It excludes engine and private application Swift sources. Browser
exports and platform limitations remain described in the integration guide.
The native Swift SDK is released independently as 0.7.10.
