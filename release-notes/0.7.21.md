# SiriusMarkdown 0.7.21

Supported HTML text can retain an authored opaque sRGB foreground color through
native preparation, rich copy and text-flow PDF export. Only literal `#RGB` and
`#RRGGBB` colors are consumed; `color:initial` restores theme ink. Other CSS does
not gain layout, resource or execution authority. Semantic links and native
selection keep their own foreground styling. CoreText confines each authored
color to its glyph runs, including surrounding plain text and native decorations.

`MarkdownTextColor` represents the bounded color value. `MarkdownInlineRun`
exposes `textColor` and `styleSources`; `MarkdownInlineStyleSource` describes
exact opening and closing UTF-8 byte and line ranges for authored semantic
styles. Recovered or ambiguous HTML does not grant delimiter-edit authority.
Hosts must still validate the current source revision before applying edits.
The original inline-run initializer remains available.

Preparation cache identity includes color and complete style bounds. Width
changes continue to reuse prepared measurements; painting does not parse or
measure text. Package products and minimum platforms remain unchanged.

The independently versioned browser 0.2.13 distribution includes the same shared
engine source and preserves its inline colors and style ranges through the
browser APIs. Native AppKit/UIKit input and CoreText export integrations remain
separate from browser editing and printing.
