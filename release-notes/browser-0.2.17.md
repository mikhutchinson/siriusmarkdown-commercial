# SiriusMarkdown Browser 0.2.17

The browser renderer preserves dollar amounts with their original symbols,
spacing and emphasis. It also keeps equations following those amounts
available to the math renderer. The fix applies as Markdown streams and
after the document finishes.

Both WebAssembly reactors include the shared engine from native SDK 0.7.25.
Update the workers, JavaScript, fonts and both WASM modules together.
