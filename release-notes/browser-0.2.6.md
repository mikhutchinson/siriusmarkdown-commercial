# SiriusMarkdown browser 0.2.6

October 20, 2026

The shared WASM diagram engine expands Gantt scheduling, GitGraph topology and
configuration, compact flow links, sequence activities, quadrant styles and XY
series, labels and legends. Parsing and quantitative layout use the same Swift
implementation as the native SDK.

Pie diagrams add true donuts, all five legend positions, complete wrapped keys,
paint/text/stroke controls and contrasting percentage labels. Duplicate and zero
rows retain their values. Precise quantities and totals beyond the floating-point
sum range preserve truthful shares. Quoted and escaped strings, multiline labels,
comments and authored accessibility metadata share strict completed-input and
progressive parsing. Metadata stays separate from painted labels and Find.

Readable previews and PDF export preserve each prepared diagram’s canvas with
its text and palette. Dark titles and legends retain their intended contrast,
including when printing backgrounds is disabled; diagram dimensions and fonts
remain unchanged. Cloned SVG fragments also keep independent marker, clipping
and gradient references, so hiding the live reader cannot remove arrowheads.

Prepared SVG remains vector through zoom and export. Complete logical labels,
exact source panes and source-backed Find survive wrapping and streaming updates.
Journey and Timeline labels use contrasting ink over their prepared fills.
Browser surface tints match native PDF colors, and dense figures avoid redundant
synchronous layout during mounting.
See the [diagram guide](../Docs/Native-Mermaid.md) for supported controls and limits;
unsupported completed input retains source rather than silently dropping data.

Find highlights complete text after multibyte characters, preserves whole Unicode
scalars and reveals the active result inside the visible reader. The downloadable
playground searches while typing and starts each new query at its first match.
Diagram Find highlights the matching SVG glyphs, including in Safari;
Next/Previous reveal individual matching labels. Temporary Find paint stays out
of downloaded SVG, readable snapshots and printed documents.

Upgrade consumer JavaScript, workers, fonts and both WASM modules together. The
public playground stays on static hosting with direct browser requests and its
existing CORS limits. The optional Node gateway remains available for self-hosted
integrations. Native SDK 0.7.9 is independently versioned.
